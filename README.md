# Blog

Thème WordPress personnalisé développé avec les thèmes de blocs (Block Theme).

## Structure

- `templates/` : modèles du site
- `parts/` : en-tête et pied de page
- `assets/` : CSS, JavaScript et images
- `theme.json` : configuration globale du thème
- `functions.php` : chargement des ressources

## Développement

Le thème est développé avec :

- WordPress
- Visual Studio Code
- Git
- GitHub
